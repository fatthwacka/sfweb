## 🔧 System Architecture (Simplified - No Version Control)

### **Backend API Endpoint**
- **Route**: `PUT /api/content-management/brand-intelligence/clients/:clientId/brand-profile`
- **Method**: Delete existing → Insert new (simple replace)
- **Authentication**: Requires user session
- **Validation**: Basic field validation and defaults

### **Frontend Components**
- **Main Component**: `BrandProfileEditor.tsx`
- **Modal System**: Full-screen overlay with form sections
- **State Management**: React useState with TanStack Query mutations
- **Auto-save**: Manual save via "Save Changes" button

### **Database Schema (Supabase)**
- **Table**: `client_brand_profiles`
- **Primary Key**: `id` (UUID)
- **Client Link**: `client_id` (FK to content_clients)
- **No Versioning**: Single active record per client
